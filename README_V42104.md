# KeySuite V4.21.04

- Dashboard Brand / Series Settings: Brand-level checkbox selects or clears all currently visible/eligible series under that Brand. Partial series selection shows an indeterminate Brand checkbox.
- Eligibility rules from V4.21.03 are preserved: no customer = User Assigned only; selected customer = User Assigned × Customer Price Preference.
- CHC C4 (G1) Enhanced is available again, but remains unticked by default.
- Quick Selection supports Enhanced independently for CHC C4 and CHC C6. Enhanced preference is saved per CHC generation/series.
- CHC C4 remains based on the G1 hydraulic database and IE2 motor defaults.
- No Supabase database migration or Edge Function deployment is required for V4.21.04.
